# Residential Property Design Skill

## Purpose

Create premium residential property websites using a
contemporary nature + architectural editorial design direction.

This skill is specifically designed for:
- residential property landing pages
- housing developments
- real estate projects
- property marketing websites
- developer websites

## Required References

Before creating or modifying UI:

1. Read DESIGN.md.
2. Read ANTISLOP.md.
3. Follow DESIGN.md as the visual source of truth.
4. Use ANTISLOP.md as the quality filter.

## Core Principles

Prioritize:

- real property photography
- architecture
- typography
- whitespace
- editorial composition
- natural materials
- restrained emerald accents
- clear conversion paths

Avoid:

- generic SaaS layouts
- excessive cards
- excessive rounded corners
- excessive gradients
- glassmorphism
- decorative blobs
- fake statistics
- fake testimonials
- generic AI copy
- unnecessary animation

## Implementation

When implementing:

1. Inspect the existing project stack.
2. Reuse existing components when possible.
3. Do not introduce a new UI framework without reason.
4. Follow the existing coding conventions.
5. Use semantic HTML.
6. Make responsive behavior intentional.
7. Prefer CSS transitions over unnecessary JavaScript animation.
8. Optimize images.
9. Preserve accessibility.
